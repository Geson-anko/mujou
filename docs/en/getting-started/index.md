# Getting Started

This section is for people who use Mujou for the first time. It assumes you can use Python and PyTorch.

Read in this order.

1. [Installation](installation.md): install Mujou and check that it works
2. [Quickstart](quickstart.md): run the smallest program and read its output
3. [Concepts](../concepts/index.md): learn how to think about nodes, ports, networks, global time, and state
4. [User Guide](../user-guide/index.md): write your own nodes and networks

To find a program close to what you want to build, see the list of [Examples](../examples/index.md).
