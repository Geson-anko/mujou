# Mujou

Asynchronous Distributed Deep Learning Library for Continuous Learning
{ .mujou-tagline }

mujou は、推論と学習を同時に行い続ける深層学習フレームワークである。PyTorch のコードでノードを書き、ノードをつないだネットワークを走らせる。

!!! warning "開発の初期段階"

    mujou はまだ開発の初期段階にある。API は予告なく変わることがある。

## 🌱 学び続けるネットワーク

従来の機械学習は、学習を終えたら重みを固定して推論する。mujou のネットワークは、走っている間ずっと入力を受け取って出力を出し、同時に学び続ける。

学習と推論を切り替えるモードも、エポックも無い。

名前は「諸行無常」の「無常」（常が無いこと）から取った。ストリームから学び続け、常に変わり続ける機械を作るためのフレームワークだからである。リアルタイム処理やロボティクスのように、動きながら学ぶ用途を狙う。

## ✨ 特徴

- 🔄 **推論と学習を同時に**: 学習のモードも推論のモードも、エポックも無い
- 🧩 **PyTorch で書くノード**: 各ノードは普通の PyTorch のコードで書き、ノードの内側で同期的に実行する
- ⚡ **非同期のノード**: 各ノードは自分のスレッドで更新し、ほかのノードを待たない
- ⏱️ **連続時間**: ノードは、実際に経った時間 `dt` に比例して更新する
- 💾 **止めずに状態を取る**: 走っているネットワークの状態を取り、後でその状態から走らせ直せる
- 🧪 **決定的なテスト**: 仮想のタイマーと手動の更新でノードをテストできる

## ⚙️ 動き方

```mermaid
flowchart LR
    H["ホスト（あなたのプログラム）"] -->|"入力を書く"| A["ノード A"]
    A -->|"最新の値"| B["ノード B"]
    B -->|"出力を読む"| H
```

各ノードは自分のスレッドで更新を繰り返し、ほかのノードを待たない。読むのは、隣のノードが最後に送った値である。

ホスト（ネットワークを走らせるプログラム）は、走っているネットワークに入力を書き、出力を読む。
