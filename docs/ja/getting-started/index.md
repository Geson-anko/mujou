# はじめに

この章は、mujou を初めて使う人のためのものである。Python と PyTorch を使えることを前提にする。

次の順に読む。

1. [インストール](installation.md): mujou を入れ、動くことを確かめる
2. [クイックスタート](quickstart.md): 最小のプログラムを走らせ、出力を読む
3. [概念](../concepts/index.md): ノード・Port・ネットワーク・グローバル時間・状態の考え方を知る
4. [ユーザーガイド](../user-guide/index.md): 自分のノードとネットワークを書く

書きたいものに近いプログラムを探すときは、[サンプル](../examples/index.md)の一覧を見る。
