# ユーザーガイド

この章は、mujou でノードを書き、ネットワークに組み、走らせる手順を説明する。ノード・Port・ネットワーク・グローバル時間・状態の考え方は[概念](../concepts/index.md)の章にある。この章は、それを読んだ前提で書く。

## ページの地図

作業の順に並べてある。

| ページ                                      | 読むとできること                                                                     |
| ------------------------------------------- | ------------------------------------------------------------------------------------ |
| [ノードを書く](writing-a-node.md)           | ノードのクラスを書く。Port の宣言、hook、`dt` に比例した更新、実行の周期、状態の確保 |
| [ネットワークを組む](building-a-network.md) | ノードをつなぐ。分岐と合流、入れ子、外に公開する Port、構築した構造の確かめ方        |
| [ネットワークを走らせる](running.md)        | `mujou.run` で走らせ、ホストから入力を書き、出力を読み、終了させる                   |
| [ネットワークを束ねる](compose.md)          | 複数のネットワークを 1 つの実行で走らせる。別々の実行に分けるべき場面を判断する      |
| [状態の保存と復元](state.md)                | 走らせたまま状態を取り、保存し、その状態から走らせ直す                               |
| [時間の制御](time.md)                       | 時間の速さを変える。実行ごとのタイマーを使う                                         |
| [ノードの中の PyTorch](torch.md)            | ノードの中で `nn.Module`・GPU・ノード内の BP を使う                                  |
| [更新手法](update-rules.md)                 | 学習則をノードに書く                                                                 |
| [例外と終了](errors.md)                     | ノードの例外がどう伝わり、ネットワークがどう止まるかを知る                           |
| [テスト](testing.md)                        | 仮想のタイマーと手動の実行で、ノードを決定的にテストする                             |

## 最初に読むページ

初めてなら、[ノードを書く](writing-a-node.md)、[ネットワークを組む](building-a-network.md)、[ネットワークを走らせる](running.md)の順に読む。この 3 ページで、自分のノードを書いて走らせるまでの手順がそろう。

各ページのコード例は `examples/` のプログラムを取り込んだもので、テストで実行している。
