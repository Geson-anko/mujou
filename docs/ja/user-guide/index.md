## 🚩 最初に読むページ

初めてなら [ノードを書く](writing-a-node.md) → [ネットワークを組む](building-a-network.md) → [ネットワークを走らせる](running.md) の順に読む。この 3 ページで自分のノードを書いて走らせるまでの手順がそろう。
