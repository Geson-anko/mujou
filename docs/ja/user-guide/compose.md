# ネットワークを束ねる

複数のネットワークを 1 つの実行で走らせるには、`mujou.run(a, b)` に並べて渡すか、`mujou.Compose` で束ねる。このページは、その書き方と、束ねずに別々の実行に分けるべき場面を説明する。

## 書き方

```python
--8<-- "examples/compose.py:38:70"
```

`mujou.run(a, b)` は `mujou.run(Compose(a, b))` と同じである。名前を付けたいときは `Compose` をキーワード引数で使う。

束ねたネットワークは、`Compose` の名前の下にパスを持つ。

| 書き方                  | `a` の中のノード `l1` のパス |
| ----------------------- | ---------------------------- |
| `mujou.run(a)`          | `"l1"`                       |
| `mujou.run(a, b)`       | `"0.l1"`                     |
| `Compose(a, b)`         | `"0.l1"`                     |
| `Compose(enc=a, dec=b)` | `"enc.l1"`                   |

ノード 1 つを渡す `mujou.run(node)` も、ネットワーク 1 つのときと同じく名前を足さない。ノードのパスは `""`、その Port のパスは `"prev"` などになる。`Compose(node)` は名前を足すので、ノードのパスは `"0"` になる。

パスは状態の木のキーになる。保存した状態を復元するときは、保存したときと同じ形（同じ順、同じキーワード）で束ねる（[状態の保存と復元](state.md)）。

キーワードには次の名前を使えない。空の名前、`.` を含む名前、`_` で始まる名前、`build` など `Network` の属性の名前、位置で渡したものの名前（`Compose(a, **{"0": b})` の `"0"`）である。使うと `ValueError` になる。

## 束ねる前につなぐ

束ねたネットワーク同士は、束ねる前に `connect` でつないでおけば、つながったまま走る。`Compose` 自体は何もつながない。上の例では `enc.connect(dec)` の後に `Compose(enc=enc, dec=dec)` で束ねている。

入力を書く Port と出力を読む Port は、渡したネットワークの Port をそのまま使う（`enc.prev`、`dec.next`）。`Compose` の属性を経由しなくてよい。

1 つのネットワークを `mujou.run(a)` で単独で走らせると、そのネットワークは単独で構築される。その後で同じネットワークを `mujou.run(a, b)` に渡すと、最初の実行が走っている間でも終わった後でも `RuntimeError` になる。最初からまとめて走らせるか、新しいインスタンスを作る。

## 束ねるか、別々に走らせるか

束ねたネットワークは 1 つの実行になる。1 つの実行は、1 本のタイマー、1 つの状態の木、1 つの終了を共有する。束ねるか分けるかは、これを共有したいかで決める。

| 共有されるもの | 束ねたとき                                            | 別々の実行で、別々の `Timer` を渡したとき    |
| -------------- | ----------------------------------------------------- | -------------------------------------------- |
| つなぐこと     | できる                                                | できない。別の実行の Port はつなげない       |
| 状態の取得     | 全ノードを同時に止め、同じ時刻の状態を 1 つの木で取る | 実行ごとに取る。取得で止まるのはその実行だけ |
| 時間の速さ     | 全ノードで同じ                                        | 実行ごとに変えられる                         |
| 例外           | 1 つのノードの例外で、全ネットワークが終了する        | 例外を投げたノードの実行だけが終了する       |

次の場面では、束ねずに別々の実行にし、それぞれに `mujou.time.Timer()` を渡す。

- 一方の状態を取るときに、もう一方を止めたくない
- 一方の時間を速めたり遅めたりしたい
- 一方が例外で止まっても、もう一方を動かし続けたい

別々の実行でも、`timer` を渡さなければ、どちらもグローバルタイマーを共有する。その場合、一方で状態を取るともう一方の時間も止まる。止め合いたくないなら、別々の `Timer` を渡す。

```python
timer = mujou.time.Timer()
with mujou.run(net, timer=timer) as run:
    timer.sleep(2.0)   # この実行のタイマーで待つ
```

`Timer` の使い方は[時間の制御](time.md)にある。
