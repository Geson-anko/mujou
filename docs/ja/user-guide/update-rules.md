# 更新手法

mujou は、ノードの状態をどう更新するか（更新手法）をフレームワークに組み込んで固定しない。更新手法はノードの内側に閉じており、ノードごとに選び、差し替えられる。

- ノード・Port・実行の基盤は、特定の学習則を前提にしない。ノードの `on_update(dt)` に書いた更新が、そのノードの更新手法である
- 既定の更新手法は PC-ALM（Augmented Lagrangian Predictive Coding、<https://pub.sakana.ai/pc-alm/>）である。局所的な更新で誤差逆伝播（BP）に近い性能を出せると報告されているので選んだが、暫定的な選択である
- BP も、1 つのノードの内側に閉じていれば、更新手法の 1 つとして使える。書き方は[ノードの中の PyTorch](torch.md)にある

!!! note "PC-ALM のノードは未実装"

    PC-ALM のノードは、モジュール `mujou.pc` から提供する予定で、まだ実装していない。それまでは、`mujou.Node` を継承し、`on_update(dt)` に更新式を自分で書く（[ノードを書く](writing-a-node.md)）。
