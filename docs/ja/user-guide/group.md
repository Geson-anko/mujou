# 🗂️ ネットワークを束ねる

複数のネットワークを 1 つの実行で走らせるには、`mujou.run(a, b)` に並べて渡すか `mujou.Group` で束ねる。

このページでは書き方と、束ねずに別々の実行に分けるべき場面を説明する。

## 書き方

```python
--8<-- "examples/group.py:group"
```

`mujou.run(a, b)` は `mujou.run(Group(a, b))` と同じ。名前を付けたいときは `Group` にキーワード引数で渡す。

束ねたネットワークのパスは `Group` が付けた名前の下に入る。

| 書き方                | `a` の中のノード `l1` のパス |
| --------------------- | ---------------------------- |
| `mujou.run(a)`        | `"l1"`                       |
| `mujou.run(a, b)`     | `"0.l1"`                     |
| `Group(a, b)`         | `"0.l1"`                     |
| `Group(enc=a, dec=b)` | `"enc.l1"`                   |

パスは状態の木のキーになる。位置で渡すかキーワードで渡すかでパスが変わる。

!!! warning "復元するときは同じ形で束ねる"

    保存した状態を復元するときは、保存時と同じ形で束ねる。順番を揃え、キーワードは保存時に使った箇所でだけ使う。形が違うとパスが合わず、`mujou.run(..., state=tree)` が `ValueError` になる（[状態の保存と復元](state.md)）。

ノード 1 つを渡す `mujou.run(node)` も、ネットワーク 1 つのときと同じく名前を足さない。ノードのパスは `""`、その Port のパスは `"prev"` などになる。

`Group(node)` は名前を足すので、ノードのパスは `"0"` になる。

空の名前や `.` を含む名前など、使えない名前をキーワードにすると `ValueError` になる。

## 束ねる前につなぐ

束ねる前に Port を `connect` でつないでおけば、束ねたネットワーク同士はつながったまま走る。`Group` 自体は何もつながない。上の例では `enc.next.connect(dec.prev)` の後に `Group(enc=enc, dec=dec)` で束ねている。

入力を書く Port と出力を読む Port には、渡したネットワークの Port をそのまま使う（`enc.prev`、`dec.next`）。`Group` の属性を経由する必要はない。

!!! warning "単独で構築したネットワークは後から束ねられない"

    `mujou.run(a)` で単独で走らせたネットワークは単独で構築される。その後で同じネットワークを `mujou.run(a, b)` に渡すと、最初の実行が走っている最中でも終わった後でも `RuntimeError` になる。最初からまとめて走らせるか、新しいインスタンスを作る。

## 束ねるか、別々に走らせるか

束ねたネットワークは 1 つの実行になり、1 本のタイマー、1 つの状態の木、1 つの終了を共有する。

束ねるか分けるかは、これらを共有したいかどうかで決める。

| 共有されるもの | 束ねたとき                                            | 別々の実行で、別々の `Timer` を渡したとき |
| -------------- | ----------------------------------------------------- | ----------------------------------------- |
| つなぐこと     | できる                                                | できない。別の実行の Port はつなげない    |
| 状態の取得     | 全ノードを同時に止め、同じ時刻の状態を 1 つの木で取得 | 実行ごとに取得。止まるのはその実行だけ    |
| 時間の速さ     | 全ノードで同じ                                        | 実行ごとに変えられる                      |
| 例外           | 1 つのノードの例外で全ネットワークが終了              | 例外を投げたノードの実行だけが終了        |

次の場面では束ねずに別々の実行にし、それぞれに `mujou.time.Timer()` を渡す。

- 一方の状態を取得するとき、もう一方を止めたくない
- 一方の時間を速めたり遅くしたりしたい
- 一方が例外で止まっても、もう一方は動かし続けたい

!!! warning "timer を渡さない実行はグローバルタイマーを共有する"

    別々の実行でも `timer` を渡さなければ、どちらもグローバルタイマーを共有する。その場合、一方で状態を取得するともう一方の時間も止まる。止め合いたくないなら別々の `Timer` を渡す。

```python
timer_a, timer_b = mujou.time.Timer(), mujou.time.Timer()
with mujou.run(a, timer=timer_a) as run_a, mujou.run(b, timer=timer_b) as run_b:
    timer_a.sleep(2.0)   # a の実行のタイマーで待つ
```

`Timer` の使い方は[時間の制御](time.md)を参照。
