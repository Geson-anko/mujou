2026-10-19、M:N の実装中にユーザーが「すべての質問は最後にまとめてお願いします。推奨で進みます」と指示した。

**Why:** 推奨案を添えて都度 AskUserQuestion で止めると、並列で動いている作業の進みが質問のたびに待たされる。ユーザーは推奨案を受け入れることが多い。

**How to apply:** 計画者やレビュアーから確認事項が上がっても、推奨案で進め、決めた内容と理由を記録する（memory や計画書）。ユーザーへの質問は、作業の区切り（報告の最後）に一覧でまとめて出す。取り返しのつかない操作（main への直接の変更、破壊的な git 操作、外部への公開）は従来どおり先に確認する。
