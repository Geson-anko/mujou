2026-10-16 のユーザーの回答。利用者向けのテストの口は公開する。mujou 自身のテスト（既定のノードのテストを含む）と利用者のテストは、同じ公開の口を使う。名前は `mujou.testing` など。中身は仮想時計と、ノードを手で 1 ステップずつ進める仕組み。実装は後の段階で、ドキュメントには User Guide の Testing ページと API リファレンスの Testing ページの枠だけがある。

**Why:** 利用者も自分のノードを決定的にテストできる必要がある。mujou と利用者で別の口を持つと、片方だけが古くなる。

**How to apply:** 今ある `_manual` などの private なテスト用の口は、`mujou.testing` を作るときにそこへ移す。同じ日の決定「利用者が使うべきでないものは公開の API に見せない」の対象は、テスト以外の内部の口になる。
