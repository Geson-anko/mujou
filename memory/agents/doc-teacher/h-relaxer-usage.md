## 評価用問題
### Q1 11 ノードの深い `pc.Chain`。`tau.h` は 20 ms、周期は `tau.h / 4`。credit が鎖を渡る周期数を減らしたい。`relaxer=` に何を渡すか
- 要点: `pc.HeavyBall(tau=...)`
- 要点: `tau = tau.h / 4` = 5 ms（0.005）

### Q2 `pc.Chain(..., relaxer=pc.HeavyBall(tau=0.005))` を作った。`pc.Output` には relaxer を渡せるか。各 `pc.Layer` の速度は共有されるか
- 要点: `pc.Output` は `h` を持たないので取らない
- 要点: 共有されない。設定は状態を持たず、各 `Layer` が自分の `h` に bind して自分の速度を持つ

### Q3 `pc.HeavyBall` を使っている。(a) 新しいサンプルが来たとき (b) そのノード自身の重みが跳んだとき、速度はどうなるか
- 要点: (a) 捨てる（0 に戻す）
- 要点: (b) 捨てない

### Q4 自作の relaxer で、`h` が毎ステップ少し 0 に縮む項（leak）を足した。使ってよいか。理由も
- 要点: だめ
- 要点: 不動点が `F = 0` のところでなければならない。そうでないと `lam` が BP の credit にならない

### Q5 `HeavyBall` を使っている。周期だけを `tau.h / 16` に縮め、`tau` は `tau.h / 4` のままにした。そのまま走らせてよいか
- 要点: 危ない。1 更新あたりの係数 `exp(-dt/tau)` が約 0.78 になり、0.8 で発散した値に近い
- 要点: 力は `dt` ではなく 1 更新に掛かるので、周期を変えたら `tau` も合わせて選び直す

### Q6 実行中の状態から、あるノードの速度を読みたい。どこにあるか。`pc.Euler` のときはどうなるか
- 要点: `run.state_dict()["nodes"][path]["state"]["relaxer"]["velocity"]`
- 要点: `pc.Euler` は空の dict

## 保留問題
### H1 3 層の浅い MNIST 風の `pc.Chain` を組む。`relaxer=` はどうするか。理由も
- 要点: 省略（既定の `pc.Euler()`）。浅い鎖には要らない

### H2 `pc.HeavyBall(tau=math.inf)` を渡すとどうなるか
- 要点: `ValueError`（`tau` は有限で > 0）

### H3 `HeavyBall` を使うと `h` の落ち着く先（不動点）は `Euler` と変わるか。`lam` の進め方は
- 要点: 変わらない（`F = 0`、速度 0）。`lam` は `h` を動かした後に、どの relaxer でも従来どおり進める
