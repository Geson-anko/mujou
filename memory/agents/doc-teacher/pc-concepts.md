# docs/ja/topics/pc-concepts.md 理解度テスト

## 対象
- ファイル: docs/ja/topics/pc-concepts.md（新規、日本語のみ）
- 読者と用途: PyTorch と BP、mujou の基本（ノード・Port・dt）を知るが PC を知らない利用者。mujou.pc の部品の役割・流れるメッセージ・Layer の on_update の順・LearnClock の Tick・jumps・TimeConstants を理解し、topics/pc.md の「自分のノードを書く」と examples/pc_merge.py を名前に迷わず読む
- 方針: 途中でオーケストレーターから「主題は PC-ALM の理論でなく mujou.pc モジュールの仕組み。理論は最小限」と指示された（ユーザーの指摘）

## 評価用問題
### Q1 入力が 2 つあるノードを自作したい。pc.Layer をそのまま使うか、pc.functional と pc.LearnClock で書くか。理由も。
- 要点: functional と LearnClock で書く／Layer は入力が 1 つ（Layer で書けないノードは部品で書く。Layer 自体もそれらの組み合わせ）

### Q2 pc.Layer の prev の Port は何を受け取り、何を送るか。
- 要点: Activity を受け取る／g_in（前のノードへの勾配）を送る

### Q3 目標 y を活動とは別の Port で Output に届ける設計にすると、何が起きうるか。
- 要点: Output が活動と目標を別々の瞬間に読む／別のサンプルの予測と目標が組になりうる（Port は最新値だけ、ノードは非同期）

### Q4 Layer の 1 回の on_update で、g_in を前のノードへ送るのと relax_ で h を動かすのはどちらが先か。また vjp の delta はどの時点の h と lam で作るか。
- 要点: g_in を送るのが先／更新前の h・lam

### Q5 自作のノードで relax_ と learn_ に渡す時間は、Tick のどのフィールドか。それぞれ何の時間か。
- 要点: relax_ に tick.dt（max_dt で打ち切った dt）／learn_ に tick.elapsed（前に学んでからの打ち切った dt の和）

### Q6 learn_interval=0.024 のノードに、書き込みから 0.03 秒経った新しいサンプルが初めて届いた。この更新で学ぶか。理由も。
- 要点: 学ばない／new が True の更新では学ばない（delta がまだ前の入力のもの）

### Q7 Layer が受け取った Activity の jumps が、前回読んだ値と違っていた。Layer は何をするか。
- 要点: h を予測と一緒に付け替える h ← mu + (h − mu_last)（r と lam を保つ）／自分の jumps を 1 進める

### Q8 learn_interval=None のノードが重みを学んだ。次の更新で自分の jumps を進めるか。理由も。
- 要点: 進めない（跳びは自分の h に足すだけ）／毎回進めると次のノードが毎回付け替え、深い鎖が発散する

### Q9 TimeConstants(h=4e-3, lam=8e-3, theta=1.0) の既定の周期と max_dt はそれぞれ何秒か。
- 要点: 周期 1e-3（h/4）／max_dt 2e-3（min(h/2, 3*lam)）

### Q10 バッチの平均勾配で学ばせたい。vjp に渡す delta や損失を自分でバッチ平均にしてよいか。1/B はどこで掛かるか。
- 要点: しない（損失はサンプルごと、勾配はバッチの和）／1/B は learn_ だけが掛ける（lam がサンプルごとの credit になる）

### Q11 mask がすべて False のバッチを見せている間、Layer の h・lam・重みはそれぞれ動くか。（R2 で H2 から移した）
- 要点: h と lam は動く／重みは学ばない（learn_ を呼ばない）

## 保留問題
### H1 TimeConstants の lam に math.inf を渡すと lam はどうなるか。平衡点で重みの勾配は BP と一致するか。
- 要点: lam は 0 のまま（ただの predictive coding）／BP と一致しない

### H3 pc.Output は受け取った Activity の jumps を読むか。理由も。
- 要点: 読まない／h（自分の活動）を持たないので付け替えるものがない
