    Networks¶

    mujou.Network ¶

    Network()

    Bases: Component

    A composite of nodes and other networks, declared as attributes.

    Assign nodes and networks as attributes, connect their ports with Port.connect, and expose the ports the outside should reach as attributes of the network (by convention prev and next for the previous and the next side, e.g. self.prev = self.l1.prev). The network registers what is assigned, as nn.Module registers submodules, so nodes and networks in lists or dicts are not part of it. A network is a build-time structure: its nodes still run independently and asynchronously.

    Call super().__init__() before assigning a node, a network or a port. Declare ports as instance attributes (in __init__), not class attributes, and do not use the names of the methods below for attributes.

    mujou.run(net) builds the network (build) and runs it; the Run it returns is how the host talks to the running nodes.

    Example::

    class Stack(Network):
    def __init__(self) -> None:
        super().__init__()
        self.l1 = Hidden(784, 256)
        self.l2 = Hidden(256, 256)
        self.l1.next.connect(self.l2.prev)
        self.prev = self.l1.prev  # expose the previous side
        self.next = self.l2.next  # expose the next side


class Classifier(Network):
    def __init__(self) -> None:
        super().__init__()
        self.body = Stack()
        self.head = Head()  # a node with prev, next and teacher ports
        self.body.next.connect(self.head.prev)  # l2.next <-> head.prev
        self.prev = self.body.prev  # the input
        self.teacher = self.head.teacher  # the target, a port of head


net = Classifier()
with mujou.run(net, inputs={net.prev: x0, net.teacher: y0}) as run:
    run.write({net.prev: x, net.teacher: y})  # switch together
    mujou.time.sleep(0.1)  # present the input for 0.1 s of global time
    prediction = run.read(net.head.next)
    state = run.state_dict()

    build ¶

    build() -> Graph

    Check the structure of this network as the root, freeze it and return its graph.

    After build, no port in the tree takes new connections, and no part of the tree, this network included, can become part of a bigger network: build only the network you will run. Calling it again returns the same graph. mujou.run calls it.

    RAISES DESCRIPTION
    RuntimeError

    Part of the tree (a node, a network or a port) belongs to another built network, or this network is part of a built one.
    ValueError

    The structure is invalid: the tree has no node; a component appears at two paths; a port is owned by two nodes (or under two names); a port is declared as a class attribute; a network exposes a port that no node inside it owns; or a channel leads to a port outside the tree.

    mujou.Group ¶

    Group(*components: Node | Network, **named: Node | Network)

    Bases: Network

    A network of the given nodes and networks side by side, unconnected unless they were connected before.

    One given by position is at the path of its position ("0", "1", ...) and one given by keyword at its keyword, so the node l1 of Group(a, b) is "1.l1" in b and that of Group(enc=a) is "enc.l1"; a node n in Group(n, a) is "0", as if it were an attribute "0" of a network. Group(n) of one component still puts it at "0". mujou.run(a, b) runs Group(a, b); mujou.run(a) runs a alone as the root.

    Example::

    enc, dec = Encoder(), Decoder()
enc.next.connect(dec.prev)
with mujou.run(Group(enc=enc, dec=dec)) as run:
    state = run.state_dict()  # nodes "enc.l1", ..., "dec.l1", ...
    RAISES DESCRIPTION
    TypeError

    A value is neither a Node nor a Network.
    ValueError

    A keyword is empty, holds a . (a path would be ambiguous), starts with _, is the name of an attribute of Network (such as build), or is the path of a position.

    build ¶

    build() -> Graph

    Check the structure of this network as the root, freeze it and return its graph.

    After build, no port in the tree takes new connections, and no part of the tree, this network included, can become part of a bigger network: build only the network you will run. Calling it again returns the same graph. mujou.run calls it.

    RAISES DESCRIPTION
    RuntimeError

    Part of the tree (a node, a network or a port) belongs to another built network, or this network is part of a built one.
    ValueError

    The structure is invalid: the tree has no node; a component appears at two paths; a port is owned by two nodes (or under two names); a port is declared as a class attribute; a network exposes a port that no node inside it owns; or a channel leads to a port outside the tree.

    mujou.Graph ¶

    Graph()

    The structure of a built network (or of a node run alone): what runs when mujou.run runs it.

    Network.build makes it, and mujou.run for a node given alone; it cannot be created directly, and mujou.run takes nodes and networks, not graphs. It is a different object from the network it was built from: the network declares the structure, and the graph is what runs. A graph runs once.

    nodes property ¶

    nodes: tuple[tuple[str, Node], ...]

    (path, node) for every node in the tree, depth first in attribute definition order.

    A path is the dotted attribute path from the root, e.g. "body.l1"; a node that is itself the root (mujou.run(node)) is at "".

    port_path ¶

    port_path(port: Port[Any, Any, Any]) -> str

    Return the path of port through its owner, e.g. "body.l1.next" ("next" when the owner is itself the root).

    RAISES DESCRIPTION
    ValueError

    port is not owned by a node of this graph.

    mujou.run ¶

    run(
    component: Node | Network,
    *components: Node | Network,
    timer: Timer | None = None,
    inputs: Mapping[P, Tensor | Mapping[str, object]] | None = None,
    state: Mapping[str, Any] | None = None,
) -> Run

    Build the given nodes and networks and run them in the background; return once every node has started.

    One component alone is the root of the run: a network runs as it is (its nodes at "l1", ...), and a node is at the path "" with its ports at "prev", "next", .... Several run as Group(component, *components), nodes and networks mixed or not, so their paths start with their positions: "0" for a node given first, "1.l1", ... for the nodes of a network given second. Either way the host writes and reads the ports themselves (run.write({node.prev: x})).

    Every node's thread is set up, on_start (and, with state, the node's load_state_dict) has returned, and the run's timer runs when this returns. A network or node runs once.

    PARAMETER DESCRIPTION
    component

    The node or network to run.

    TYPE: Node | Network

    components

    More nodes and networks to run with it.

    TYPE: Node | Network DEFAULT: ()

    timer

    The time axis of the run: every node's dt, every message's time and every pause of the run is on it. None is the global timer, which mujou.time reads and every run without a timer of its own shares.

    TYPE: Timer | None DEFAULT: None

    inputs

    The initial values of unconnected single-peer ports that receive, as Run.write takes them. Written after state, they replace its values and carry its time.

    TYPE: Mapping[P, Tensor | Mapping[str, object]] | None DEFAULT: None

    state

    A tree from Run.state_dict to restore: the StateDict, or any mapping of the same items (such as a plain dict). The slots, the nodes' states (through each node's load_state_dict, after its on_start), their last update times and the timer continue from the time the tree was taken. Build the networks as the ones the tree came from: the same node paths and slots.

    TYPE: Mapping[str, Any] | None DEFAULT: None

    Example, with the node Error of the example of Run::

    node = Error()
with mujou.run(node, inputs={node.prev: torch.ones(2)}) as run:
    mujou.time.sleep(0.1)
    error = run.read(node.next)
    RAISES DESCRIPTION
    RuntimeError

    A network or node has already run ("Leaky has already run; create a new instance to run again"), or part of one belongs to another network that was built but has not run; or this is called from a node's hook.
    TypeError

    A value is neither a Node nor a Network.
    (ValueError, TypeError)

    As Network.build, Group and Run.write (for inputs) raise; state does not match the networks, or the timer it would set back has another run on it. Nothing has started: the same networks, given the same way, may run once the cause is gone.
    NetworkError

    A node raised while starting; the run has stopped.

    mujou.Run ¶

    Run()

    A run of networks, as mujou.run returns it: what the host uses to talk to the running nodes.

    The nodes run in the background, each on its own thread; the host's thread only writes inputs, reads outputs and takes the state:

    • write inputs, read / read_with_time / subscribe outputs, take a state_dict.
    • shutdown() to stop the run, or join() to wait until it stops.
    • After a normal end: take the final state_dict.

    A with statement shuts the run down at its end. These methods are for the host: calling them from a node's hook raises RuntimeError.

    If a node raises, the whole run stops. If that happens while mujou.run starts the nodes, mujou.run raises NetworkError; otherwise every later call of write, read, read_with_time, subscribe (and its iterator), state_dict, shutdown and join raises it. Its __cause__ is the node's exception. The state at the exception is not kept.

    A run keeps running when the host drops it, until shutdown or, at the latest, the interpreter's exit (which waits for on_stop). At the exit, the runs start stopping once the main thread has ended, before the interpreter joins the non-daemon threads, and the exit waits until they have stopped.

    Example::

    from typing import override

import torch

import mujou
from mujou import NextPort, Node, Port, PrevPort, TensorSpec

VECTOR = TensorSpec((2,))


class Error(Node):  # sends its input minus its teacher
    def __init__(self) -> None:
        super().__init__()
        self.prev = PrevPort(recv=VECTOR)
        self.teacher = Port(recv=VECTOR)
        self.next = NextPort(send=VECTOR)

    @override
    def on_update(self, dt: float) -> None:
        super().on_update(dt)
        self.next.send(self.prev.recv() - self.teacher.recv())


node = Error()
x, y = torch.ones(2), torch.zeros(2)
with mujou.run(node, inputs={node.prev: x, node.teacher: y}) as run:
    run.write({node.prev: 2 * x, node.teacher: x})  # switch together
    mujou.time.sleep(0.1)  # present the input for 0.1 s of global time
    error, t = run.read_with_time(node.next)
state = run.state_dict()  # the state at the end, to save

    timer property ¶

    timer: Timer

    The run's timer: the timer given to mujou.run, or the global timer (the one mujou.time reads) when none was given.

    Every node's dt and every time of the run is on it.

    write ¶

    write(values: Mapping[P, Tensor | Mapping[str, object]]) -> Timestamp

    Write messages to unconnected single-peer ports that receive, and return the time they carry.

    The values are detached and copied. All of them switch together and carry the same time: at any one moment, a node sees either all of them or none. (A node that reads two of them one after the other may still see a later write in between; compare the times to tell.) Any port of the tree can be written, exposed by the root or not.

    The time is the run's timer at the write, as a node's recv_with_time and the /in slots of state_dict show it; read_with_time shows the times of sends, not of writes. An empty values changes nothing and returns the time all the same.

    RAISES DESCRIPTION
    RuntimeError

    The run has stopped normally (no node reads what is written then).
    ValueError

    A port is outside the run, connected, takes many peers, or receives nothing; or a shape or the keys differ.
    TypeError

    A message or dtype differs from the spec.
    NetworkError

    The run stopped because a node raised.

    read ¶

    read(port: Port[S, Any, Any]) -> S

    Return the latest message port sent.

    Any port that sends can be read, so a connected port shows an inner node. Only send (to every peer) updates the value read here; before the first one it is the port's initial (zeros by default) or the value restored from state. The tensors are new copies on the CPU. read_with_time also returns the time it was sent at.

    RAISES DESCRIPTION
    ValueError

    port is outside the run or sends nothing.
    NetworkError

    The run stopped because a node raised.

    read_with_time ¶

    read_with_time(port: Port[S, Any, Any]) -> tuple[S, Timestamp]

    Return the latest message port sent, as read does, and the time it was sent at.

    The time is on the run's timer. A Timestamp does not say which timer it is on: compare it only with times of the same timer (with mujou.time only when the run is on the global timer).

    RAISES DESCRIPTION
    ValueError

    port is outside the run or sends nothing.
    NetworkError

    The run stopped because a node raised.

    subscribe ¶

    subscribe(
    port: Port[S, Any, Any], timeout: float = math.inf
) -> Iterator[tuple[S, Timestamp]]

    Iterate over the messages port sends, with their times.

    The first step yields the latest message at the time of this call (before the first send, the port's initial or the restored value) without waiting. Each later step waits until a newer message is sent and yields the latest; messages sent in between are skipped. Only the consumer waits: the sending node never does. The iterator ends when the run shuts down normally. Shut the run down before the program ends: without a timeout, a thread iterating here ends only with the run. In a ManualRun nothing is sent unless step is called, so a wait here without a timeout on the thread that steps never ends.

    To wait for one message that meets a condition, use wait_for.

    PARAMETER DESCRIPTION
    port

    The port to follow.

    TYPE: Port[S, Any, Any]

    timeout

    Real seconds, counted from this call, that the whole iteration may take, the time spent in the loop's body included. math.inf iterates as long as the run runs.

    TYPE: float DEFAULT: inf

    RAISES DESCRIPTION
    ValueError

    port is outside the run or sends nothing; or timeout is negative or NaN.
    TimeoutError

    From the iterator, at a step after the first that begins once timeout has passed, or that would wait past it. The iterator ends; the run keeps running.
    NetworkError

    The run stopped because a node raised (also from the iterator).

    wait_for ¶

    wait_for(
    port: Port[S, Any, Any], condition: Callable[[S], bool], timeout: float = math.inf
) -> tuple[S, Timestamp]

    Wait until port sends a message that meets condition, and return it with its time.

    Checks the latest message first, then each newer one as subscribe yields them (messages sent in between are skipped). Only the host waits: the nodes never do. In a ManualRun nothing is sent unless step is called, so a wait without a timeout on the thread that steps never ends. Here with the node Error of the example of Run::

    node = Error()
x = torch.ones(2)
with mujou.run(node, inputs={node.prev: x}) as run:
    error, t = run.wait_for(
        node.next, lambda e: torch.equal(e, x), timeout=5.0
    )
    PARAMETER DESCRIPTION
    port

    The port to follow.

    TYPE: Port[S, Any, Any]

    condition

    Called on each message on the host's thread; True ends the wait.

    TYPE: Callable[[S], bool]

    timeout

    Real seconds, counted from this call, to wait at most. math.inf waits as long as the run runs.

    TYPE: float DEFAULT: inf

    RAISES DESCRIPTION
    ValueError

    As subscribe raises.
    TimeoutError

    timeout passed first. The run keeps running.
    RuntimeError

    The run shut down normally first.
    NetworkError

    The run stopped because a node raised.

    state_dict ¶

    state_dict(timeout: float = 30.0) -> StateDict

    Copy the state of the run at one time, while it runs or after it ended normally.

    While it runs, this pauses the run's timer and nodes, copies the state and resumes, and returns once the run has resumed. It waits at most timeout for every node to pause. After a normal end, this copies the state as the nodes left it, calling each node's state_dict on this thread (an exception it raises reaches the caller as it is). The tree's timer holds the time at which shutdown asked the run to stop, as if the run had paused then (or a later update or send of an on_stop), so that a restored run goes on from there without the time that passed after the end.

    The tree is a copy (later updates of the nodes do not change it), a StateDict (a dict) that pickles; saving it is up to the host. Pass it to mujou.run(..., state=tree) to restore it::

    {
    "nodes": {"body.l1": ..., ...},  # each node's state_dict()
    "slots": {"body.l1.next/out": (value, time_ns, sent), ...},
    "last_update_ns": {"body.l1": int, ...},
    "timer": {"time_ns": int, "scale": float},
}

    A node is keyed by its attribute path from the root. A slot is keyed by the path of the port through its owning node ("body.l1.prev/in", not an exposed name such as "prev/in") and holds its latest message: /out what read returns, /ch0, /ch1, ... each channel, and /in what the host wrote. A node run alone is the root: it is keyed "" and its slots "prev/in", "next/out", ....

    The tensors of the tree stay on their nodes' devices. tree.cpu() moves them all to the CPU, for example before saving the tree.

    PARAMETER DESCRIPTION
    timeout

    Real seconds to wait for every node to pause (the end of its current on_update): finite and > 0. After the end there is nothing to wait for, and it is only checked.

    TYPE: float DEFAULT: 30.0

    RAISES DESCRIPTION
    RuntimeError

    This is called from a node's hook.
    ValueError

    timeout is not finite and > 0.
    PauseTimeoutError

    A node did not pause within timeout; no state is taken and the run keeps running.
    NetworkError

    The run stopped because a node raised; its state is not kept.

    shutdown ¶

    shutdown(timeout: float = math.inf) -> None

    Stop every node and return once every on_stop has returned.

    Does nothing after a normal end.

    PARAMETER DESCRIPTION
    timeout

    Real seconds to wait for the end. math.inf waits as long as it takes.

    TYPE: float DEFAULT: inf

    RAISES DESCRIPTION
    ValueError

    timeout is negative or NaN; nothing was asked.
    TimeoutError

    The run did not stop within timeout. The stop stays asked: the nodes take no more updates and the run goes on stopping in the background (an on_stop may still be running). join waits for the end.
    NetworkError

    The run stopped because a node raised.

    join ¶

    join(timeout: float = math.inf) -> None

    Wait until the run stops, without asking it to stop.

    It returns once another thread called shutdown and every on_stop has returned; if a node raises, it raises instead. If nothing stops the run and timeout is math.inf, it never returns.

    PARAMETER DESCRIPTION
    timeout

    Real seconds to wait for the end. math.inf waits as long as it takes.

    TYPE: float DEFAULT: inf

    RAISES DESCRIPTION
    ValueError

    timeout is negative or NaN.
    TimeoutError

    The run did not stop within timeout. Nothing changes: a running run keeps running.
    NetworkError

    The run stopped because a node raised.

    mujou.StateDict ¶

    Bases: dict[str, Any]

    The state tree of a run, as Run.state_dict returns it.

    A dict: index it, pickle it, save it with torch.save and pass it to mujou.run(..., state=tree) as the dict it is. It adds to and cpu, which move every tensor of the tree to one device, for example to save the state of nodes on a GPU as CPU tensors::

    torch.save(run.state_dict().cpu(), "state.pt")

    It pickles as mujou.StateDict, and import mujou allows it in torch.load with the default weights_only=True: a tree saved with torch.save loads back as a StateDict.

    to ¶

    to(device: device | str | int) -> Self

    Return a new tree with every tensor of this one on device.

    Tensors are found in the dicts (OrderedDict and other subclasses too, such as the state_dict of an nn.Module), lists and tuples of the tree, at any depth. Those containers are new, of the same type; any other value is shared with this tree. As with torch.Tensor.to, a tensor already on device is shared, not copied. A tensor that appears twice in this tree appears as one tensor in the new tree.

    This tree is not changed.

    PARAMETER DESCRIPTION
    device

    The device to move the tensors to, as torch.device takes it ("cpu", "cuda:0", ...).

    TYPE: device | str | int

    cpu ¶

    cpu() -> Self

    Return a new tree with every tensor of this one on the CPU (to).
