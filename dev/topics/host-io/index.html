    🏃 Host I/O¶

    To Use Section
    Write an input run.write Writing
    Show an input from the first update the inputs= of mujou.run Initial values
    Show an input for a given time run.timer.sleep Showing an input for a while
    Read or wait for an output run.read, read_with_time, subscribe, wait_for Reading
    Take the state run.state_dict Save and Resume
    End the run a with block, run.shutdown, run.join Ending

    Writing¶

    The host writes with Run.write only to ports that receive and are not connected (nodes write the others). A written value stays until the next write, and the nodes read it many times. Write values that belong together, such as an input and its target, in one write (why: Values that belong together).

    run.write({net.prev: x, net.teacher: y})  # x and y switch together

    Initial values¶

    Way Port What a reader gets Its time
    Nothing — The spec's initial value (Specs) None
    Port(send=..., initial=value) A port a node sends on value, until the port first sends None
    mujou.run(net, inputs={port: value}) A port the host writes value, from the first update The time the run starts
    run.write({port: value}) A port the host writes value, from the write on What write returned 
    with mujou.run(net) as run:  # the nodes start updating as soon as mujou.run returns
    run.write({net.prev: x})  # a few updates before this may read zeros

    with mujou.run(net, inputs={net.prev: x}) as run:  # x from the first update
    ...

    Showing an input for a while¶

    for x in stream:
    run.write({net.prev: x})
    run.timer.sleep(0.1)  # show x for 0.1 s of the run's time
    y = run.read(net.next)  # the output at the end of the showing time

    When you know the output to expect, wait for it with wait_for instead of sleeping (Run).

    Reading¶

    Way Suited for
    run.read Reading the latest value at any time
    run.read_with_time Telling how new the value is
    run.subscribe Handling each new output
    run.wait_for Waiting until an expected output comes

    The host reads any port of the run that sends, connected or not. Reading a connected port observes a value in the middle of the network without changing it.

    subscribe¶

    sequenceDiagram
    participant N as Node
    participant H as Host (subscribe)
    Note over H: gets the latest value v0 at once
    N-->>H: send(v1)
    Note over H: gets v1 and handles it
    N-->>H: send(v2)
    N-->>H: send(v3)
    Note over H: gets v3, the latest when it is done (v2 is skipped)
    clock = Clock()  # a node runs by itself, without a network
with mujou.run(clock) as run:
    received: list[tuple[float, float]] = []
    # timeout: give up after 5 s of real time instead of waiting forever.
    for value, t in run.subscribe(clock.next, timeout=5.0):
        if t is None:  # the zeros the port holds until the clock first sends
            continue
        received.append((value.item(), float(t)))
        if len(received) == 20:
            break

    run = mujou.run(net)
...  # dropping run does not stop it: it runs until shutdown or the interpreter's exit

    with mujou.run(net) as run:
    ...  # leaving the block calls shutdown()
