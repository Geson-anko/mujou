    PC-ALM¶

    mujou.pc ¶

    PC-ALM (augmented Lagrangian predictive coding) as nodes of mujou.

    Each node holds a part of the model and learns from its neighbors' messages only: Input takes the samples the host writes, each Layer wraps a module as one constraint h = f(h_in), and Output holds the last module and the loss. Inside a node, the module is differentiated by autograd; between nodes, activities (Activity) flow to the next node and gradients of the energy to the previous one. The target of each sample travels with its input, so the output node pairs every prediction with its own target. functional holds the stateless computations the nodes are made of, for writing nodes of your own.

    Import it as a submodule::

    import mujou.pc as pc

B = 64
tau = pc.TimeConstants(h=4e-3, lam=8e-3, theta=1.28)
carry = pc.carry_spec(TensorSpec((B,), torch.int64), batch=B)
inp = pc.Input((B, 784), carry=carry, period=tau.h / 4)
hidden = pc.Layer(
    nn.Sequential(nn.Linear(784, 256), nn.ReLU()),
    input_shape=(B, 784),
    carry=carry,
    tau=tau,
)
out = pc.Output(
    nn.Linear(256, 10),
    loss=pc.cross_entropy,
    input_shape=(B, 256),
    carry=carry,
    tau=tau,
)
inp.next.connect(hidden.prev)
hidden.next.connect(out.prev)

    Bases: Node

    A node that takes the samples the host writes and sends them on, the input x as the activity and the target with it as the carried data.

    The host writes a Sample (x, y and mask) to prev with Run.write. In each on_update the node sends x from next as the h of an Activity, carrying y, mask and the time (ns) at which the host wrote them: the nodes on the path pass them on with the activity computed from x, so that the output node pairs each prediction with its own target. A new time tells them the input changed. The epoch of the Activity counts the writes the node has seen, so that the next node moves its h with a new x even when it was written at the same time as the zeros before it (time 0). x is clamped: what the next node sends back on next is not read.

    Before the host first writes, the node sends zeros with mask False and epoch 0. The state holds the epoch ("_epoch") and the time (ns) of the last write seen ("_seen_write", -1 before any).

    Example::

    carry = pc.carry_spec(TensorSpec((B,), torch.int64), batch=B)
inp = pc.Input((B, 784), carry=carry, period=1e-3)
...
with mujou.run(net) as run:
    run.write({inp.prev: {"x": x, "y": y, "mask": torch.ones(B, dtype=torch.bool)}})

    Bases: Learner

    A node that wraps module as one constraint h = f(h_in; theta) of PC-ALM.

    It predicts mu = module(h_in) from the activity h_in of the previous node, and holds its own activity h, which it sends to the next nodes, and the dual lam of the constraint. With \(r = h - \mu\), \(\delta = r + \lambda\) and the sum \(g\) of what the next nodes send back:

    \[ \tau_h \dot h = -(r + \lambda + g),\qquad \tau_\lambda \dot\lambda = r,\qquad \tau_\theta \dot\theta = -g_\theta / B, \]

    where \(g_\theta = -J_\theta^\top \delta\) and the node sends \(g_{\mathrm{in}} = -J_h^\top \delta\) to the previous node (both from one vector-Jacobian product of module, functional.vjp). At a fixed point, \(r = 0\) (h is the forward pass) and lam is the credit \(-\partial\ell/\partial h\) of backpropagation. Inside the node, module is differentiated by autograd; between nodes, only these messages flow.

    h follows the gradient flow above, with the mu of the moment: when the nodes below relax, h_in and mu move continuously and h only relaxes towards them. Where mu jumps, h moves with it once, so that the deviation r = h - mu and lam carry over and only they do:

    • With a new sample (the carried time changed), or when the h_in it reads jumped (the epoch of the Activity changed), the node moves h <- mu + (h - mu_last) with the mu_last of its previous update. Without a target, h is thus the forward pass.
    • When it updates theta, it computes once more, without gradients, mu' = f(h_in; theta_new) at the same h_in, and moves h <- h + (mu' - mu) at the start of its next update, with mu_last <- mu'. Only the jump that theta makes moves h, not the drift of h_in. The move waits one update so that the next nodes, which may read h before they learn, see it as a jump (it is sent with a new epoch) rather than learn from it.

    The node advances its epoch once in an update that moves h with a new sample or a jump of h_in, or by a jump of theta while learn_interval is set; the next node then moves with it in turn, so a jump runs up the path with r unchanged at every node, whenever each node learns. With learn_interval=None, theta moves by dt in every update, continuously: the node moves its own h but does not advance its epoch, as moving every node above in every update would hold r rather than h as the state, which diverges in deep chains.

    Each on_update(dt):

    1. caps dt at max_dt;
    2. reads h_in and its epoch with the data carried with it, and g;
    3. notes a new input if the carried time changed;
    4. moves h by the jump of theta of the previous update, if any;
    5. computes mu, g_in and, when it learns, g_theta with the delta before this update, zero for the samples whose carried mask is False; with a new input or a new epoch of h_in, moves h with mu first;
    6. sends g_in;
    7. moves h and then lam by dt (functional.relax_);
    8. sends h with its epoch, carrying on the data that came with h_in;
    9. when it learns, moves theta by the time since its last update (functional.learn_) and computes the jump of mu it made.

    It learns in its first update once learn_interval seconds have passed since the host wrote the input (the carried time, on the run's time), and then every learn_interval seconds while the input stays, but never in the update that first sees an input (its delta is still that of the input before); with learn_interval=None, in every update. The nodes read the one timer of the run, so the nodes on a path learn at about the same time, however deep they are, and each from the relaxed delta of the same input. learn_interval must leave the credit time to go down the path and back, at least about 2 * depth * period with depth the number of nodes on the path: this is a condition of stability, not of accuracy only. With a shorter interval, deep chains can diverge however slowly theta moves, as every node then learns, and so advances its epoch, in almost every update, and the nodes above move h with every change of mu. The node does not learn when no sample of the input has a target (every carried mask is False): that time is dropped from the next update, which would otherwise learn from the delta left over from an earlier input. Nor does it keep the time of an input that changed before the node learned from it. Until the first sample reaches the node, the carried data is zeros (mask all False, time 0), so it does not learn then.

    dt is capped because the nodes are coupled explicitly: g was made from h as it was when the next node last updated. After a long stall (a loaded machine), the step dt / tau.h of every node grows at once and the coupling makes the network diverge, which no split of the step inside the node prevents. The time beyond max_dt is dropped, from the relaxation and from the weight of the next update of theta alike. The default min(tau.h / 2, 3 * tau.lam) keeps the step of h and lam stable in the node itself.

    module must treat the samples of the batch independently (no BatchNorm in training mode): the gradient of each sample must be its own. It must also be deterministic and keep no state of its own (no Dropout, no BatchNorm in training mode): an update that learns calls it once more on the same h_in to find the jump of theta, which would otherwise carry noise, or update running statistics a second time. Its parameters that require gradients learn; set requires_grad to False to freeze one. It is called once on zeros when the node is made, to find the shape and dtype of h.

    The state (Run.state_dict()["nodes"][path]) holds "module" (its state_dict), "h" and "lam" ((B, *out)), the prediction of the last update ("_mu"), the jump of theta still to add to h ("_jump", and "_jumped" whether there is one), the epoch it sends and the last one it read ("_epoch", "_seen_epoch") and when to learn ("_seen_time", "_learn_at", "_elapsed", "_learned_input"). To watch the node while it runs, read them there: Run.state_dict() pauses the run, whereas reading module, h or lam from the host's thread races with the node's updates in place.

    Example::

    B = 64
tau = pc.TimeConstants(h=4e-3, lam=8e-3, theta=1.28)
carry = pc.carry_spec(TensorSpec((B,), torch.int64), batch=B)

    nn.Sequential(nn.Linear(784, 256), nn.ReLU()),
    input_shape=(B, 784),
    carry=carry,

    learn_interval=24e-3,

inp.next.connect(hidden.prev)  # inp: a pc.Input
hidden.next.connect(out.prev)  # out: a pc.Output, or another pc.Layer

    Bases: Learner

    A node that predicts y_hat = module(h_in) and whose energy is the loss of the samples that have a target.

    It pairs h_in with the target y and mask carried in the same message, so the prediction always meets the target of the very input it was computed from, however fast the host writes. With

    \[ \ell = \sum_b \mathrm{mask}_b\, \ell_b(\hat y_b, y_b),\qquad \tau_\theta \dot\theta = -\frac{1}{B}\frac{\partial\ell}{\partial\theta}, \]

    it sends \(g_{\mathrm{in}} = \partial\ell/\partial h_{\mathrm{in}}\) to the previous node (functional.loss_vjp), zeros when no sample has a target. Each on_update(dt) caps dt at max_dt as Layer does, reads h_in with its carried data, sends g_in, sends a Prediction (y_hat with the y, mask and time it was paired with) for the host to read, and updates theta when it learns. It reads the h of the Activity only: a jump of h_in needs no move here, as the node holds no activity of its own.

    It learns as Layer does: once learn_interval seconds have passed since the host wrote the input, but not in the update that first sees it, or in every update with None. When no sample has a target, it does not learn and drops the time since the last update; so too before the first sample arrives, while the carried data is zeros (mask all False), and when the input changes before it has learned from it. B is the batch, not the number of samples with a target: a sample without one adds zero.

    loss returns the loss of each sample, (B,), such as mse or cross_entropy, and the node sums them. A loss that averages (such as nn.MSELoss()) would scale the gradient that flows back by 1 / B. module must treat the samples independently, and is called once on zeros when the node is made, as in Layer.

    The state holds "module" and when to learn ("_seen_time", "_learn_at", "_elapsed", "_learned_input"). Read it with Run.state_dict(), as for Layer.

    Example::

    out = pc.Output(
    nn.Linear(256, 10),
    loss=pc.cross_entropy,
    input_shape=(B, 256),
    carry=carry,  # pc.carry_spec(TensorSpec((B,), torch.int64), batch=B)
    tau=tau,
    learn_interval=24e-3,
)
hidden.next.connect(out.prev)
# The host: prediction = run.read(out.next); prediction["y_hat"], ...

    TimeConstants dataclass ¶

    TimeConstants(*, h: float, lam: float, theta: float)

    The time constants of the continuous-time PC-ALM, in seconds.

    A node relaxes its activity h, its dual lam and its parameters theta with

    \[ \tau_h \dot h = -(r + \lambda + g),\qquad \tau_\lambda \dot\lambda = r,\qquad \tau_\theta \dot\theta = -g_\theta / B \]

    (\(r = h - \mu\)), and a step of dt seconds moves them by dt / tau of the right-hand side (the discrete step sizes are eta_h = dt / h, alpha = dt / lam and eta_theta = dt / theta).

    lam=math.inf makes the dual stay at zero (alpha = 0, plain predictive coding), and theta=math.inf makes the parameters stay where they are (no learning). h must be finite.

    The fields are keyword-only: all three are floats, and a swap by position could not be caught by the type checker.

    Example::

    tau = TimeConstants(h=4e-3, lam=8e-3, theta=1.28)
pc_only = TimeConstants(h=4e-3, lam=math.inf, theta=1.28)
    RAISES DESCRIPTION
    TypeError

    A field is not a number (bool is not one).
    ValueError

    h is not finite and positive, or lam or theta is not positive (NaN is not).

    mse ¶

    mse(y_hat: Tensor, y: Tensor) -> torch.Tensor

    Return 0.5 * ||y_b - y_hat_b||^2 of each sample b.

    The squared error is summed over every dimension but the first. Unlike nn.MSELoss, there is no mean and the half is there, so the gradient with respect to y_hat is y_hat - y.

    mujou.pc.functional ¶

    The stateless computations of PC-ALM that the nodes of mujou.pc are made of: vjp and loss_vjp (the gradients of a node's energy), relax_ (the dynamics of h and lam) and learn_ (the update of the parameters).

    Use them to write a node of your own, such as one with several inputs. Gradients are summed over the batch; learn_ applies the 1 / B.

    Predict mu = module(h_in) and the gradients of the node's energy.

    With the activity \(h\) held fixed, the energy \(E = \tfrac12\|h - \mu + \lambda\|^2\) has the gradients

    \[ g_{\mathrm{in}} = \frac{\partial E}{\partial h_{\mathrm{in}}} = -J_h^\top \delta,\qquad g_\theta = \frac{\partial E}{\partial \theta} = -J_\theta^\top \delta, \]

    where \(\delta = h - \mu + \lambda\) and \(J\) are the Jacobians of module at h_in. Both are summed over the batch. h_in is detached first, so no graph reaches the node that sent it.

    module does not use gets zeros).
    RAISES DESCRIPTION
    ValueError

    delta is not of the shape of mu.

    loss_vjp ¶

    loss_vjp(
    module: Callable[[Tensor], Tensor],
    h_in: Tensor,
    y: Tensor,
    mask: Tensor,
    loss: Callable[[Tensor, Tensor], Tensor],
    params: Sequence[Tensor] = (),
    *,
    wrt_input: bool = True,
) -> tuple[torch.Tensor, torch.Tensor | None, list[torch.Tensor]]

    Predict y_hat = module(h_in) and the gradients of the masked loss.

    The energy of an output node is the loss of the samples that have a target,

    \[ \ell = \sum_b \mathrm{mask}_b\, \ell_b(\hat y_b, y_b),\qquad g_{\mathrm{in}} = \frac{\partial \ell}{\partial h_{\mathrm{in}}},\qquad g_\theta = \frac{\partial \ell}{\partial \theta}. \]

    A sample whose mask is False adds nothing, whatever its y is (NaN too): its y is replaced by zeros before loss sees it, and its g_in is zero. h_in is detached first.

    PARAMETER DESCRIPTION
    module

    The function f of the node, (B, *in) -> (B, *out).

    TYPE: Callable[[Tensor], Tensor]

    h_in

    The activity of the previous node, (B, *in).

    TYPE: Tensor

    y

    The target, (B, *target).

    TYPE: Tensor

    mask

    Whether each sample has a target, (B,) bool.

    TYPE: Tensor

    loss

    The loss of each sample, (y_hat, y) -> (B,), such as mse or cross_entropy.

    TYPE: Callable[[Tensor, Tensor], Tensor]

    params

    The parameters to get the gradients of.

    TYPE: Sequence[Tensor] DEFAULT: ()

    wrt_input

    Whether to get the gradient of h_in.

    TYPE: bool DEFAULT: True

    RETURNS DESCRIPTION
    tuple[Tensor, Tensor | None, list[Tensor]]

    (y_hat, g_in, g_theta) as vjp returns (mu, g_in, g_theta).
    RAISES DESCRIPTION
    ValueError

    loss does not return (B,).

    relax_ ¶

    relax_(
    h: Tensor, lam: Tensor, mu: Tensor, g: Tensor, dt: float, tau: TimeConstants
) -> None

    Move h and lam in place by one explicit Euler step of dt seconds of

    \[ \tau_h \dot h = -(r + \lambda + g),\qquad \tau_\lambda \dot\lambda = r,\qquad r = h - \mu. \]

    The step moves h first and then lam with the r of the moved h. mu and g are held fixed. The step is not split: g comes from the next nodes and stays as it was over dt, so the coupling between the nodes is explicit however finely the step is split. Keep dt short instead (Layer caps it at max_dt). tau.lam = inf leaves lam exactly as it is.

    PARAMETER DESCRIPTION
    h

    The activity of the node, (B, *out).

    TYPE: Tensor

    lam

    The dual of the node's activity, (B, *out).

    TYPE: Tensor

    mu

    The prediction f(h_in) of the node, (B, *out).

    TYPE: Tensor

    g

    The sum of the gradients the next nodes sent, (B, *out).

    TYPE: Tensor

    dt

    The time to move by, in seconds.

    TYPE: float

    tau

    The time constants; tau.h and tau.lam are used.

    TYPE: TimeConstants

    learn_ ¶

    learn_(
    params: Sequence[Tensor],
    g_theta: Sequence[Tensor],
    elapsed: float,
    tau: TimeConstants,
    batch: int,
) -> None

    Move params in place by elapsed seconds of tau_theta * dtheta/dt = -g_theta / B.

    That is one gradient step on the mean loss of the batch with the learning rate elapsed / tau.theta: p -= (elapsed / tau.theta) * g / batch. tau.theta = inf leaves params exactly as they are.

    PARAMETER DESCRIPTION
    params

    The parameters of the node.

    TYPE: Sequence[Tensor]

    g_theta

    Their gradients summed over the batch, in the same order, as vjp or loss_vjp returns them.

    TYPE: Sequence[Tensor]

    elapsed

    The time since the last update of params, in seconds.

    TYPE: float

    tau

    The time constants; tau.theta is used.

    TYPE: TimeConstants

    batch

    The batch size B.

    TYPE: int

    RAISES DESCRIPTION
    ValueError

    params and g_theta differ in length (nothing is moved).
