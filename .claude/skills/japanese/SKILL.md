# 日本語で返答する

このスキルが呼び出されたら、**以降このセッションでのユーザーへの返答をすべて日本語で行う**。明示的に「英語で」と指示されるまで日本語を維持する。

## ルール

- 散文・説明・要約・確認・質問・計画はすべて日本語で書く
- コード・コマンド・ファイルパス・識別子・ログやエラーメッセージの引用など、原文を保つべきものは英語/原語のまま残す（無理に翻訳しない）
- コミットメッセージ・PR/MR のタイトル等はプロジェクト規約（CLAUDE.md）に従う。規約が英語形式ならそれを優先し、日本語化しない
- 技術用語は無理に訳さず、自然な範囲でカタカナ/英語を併用してよい
