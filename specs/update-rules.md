# 更新手法

## 差し替え可能にする

フレームワークは、PC-ALM 以外の更新手法も与えられるようにする。**更新手法を差し替えられることは重要な要件である**。

mujou の本質は「推論と学習が同時に行われ、知能に『無常』を実現する」ことにあり、特定の学習則はそれを実現する手段のひとつに過ぎない。継続的に変化し続ける知能を実現する手段は PC-ALM に限らない。学習則をフレームワークに焼き付けてしまうと、将来よりよい手法が出てきたときに差し替えられない。

## 基盤と更新手法の分離

ノードという実行の基盤と、更新手法の実装を分離する。ノード・スロット・スケジューラは、特定の学習則を前提にしない。PC-ALM 固有の状態（双対変数 $\lambda$ など）や、やり取りする値の中身（$W^\top \varepsilon$ など）は、PC-ALM の更新手法の側に閉じ込め、基盤の型や API に直接書き込まない。

不変条件はノードの間に課し、ノードの内側の更新手法は自由に選べるようにする。BP のような非局所的な手法も、1 つのノードの内側に閉じていれば取り込める（[ノード](nodes.md#bp-の取り込み)）。

## 既定の更新手法: PC-ALM

### 位置づけ

PC-ALM は、現時点の既定の更新手法として暫定的に採用したものであり、mujou の本質ではない。既定に選んだのは、局所的な更新で BP に近い性能を出せると報告されているからである。PC-ALM は、非同期・分散的に学習するためのフレームワークとして mujou が提供する（[ネイティブコア](native-core.md#非同期分散的に学習するためのフレームワーク)）。

出典は Sakana AI の記事 "PC-ALM: Augmented Lagrangian Predictive Coding"（<https://pub.sakana.ai/pc-alm/>）。式・平衡点の性質・ハイパーパラメータ・実装上の落とし穴は skill `pc-alm` にまとめてある。

### 実装と公開元

> 状態: 未実装。`mujou.pc` はまだ無い。この節は実装するときの方針である。

PC-ALM は PyTorch で実装し、モジュール `mujou.pc` から公開する。PC-ALM のノードは、`mujou.Node` を継承したクラスとして提供する（[ノード](nodes.md#ライフサイクル-hook)）。

Rust では実装しない。PC-ALM の計算はノードの内側の行列演算なので、PyTorch の演算で書き、必要なら `torch.compile` などで速くすれば足りる。Rust のコア（`mujou._core._native`）は、学習則を知らない基盤にとどめる。`torch.compile` が free-threaded の 3.14t で、多数のスレッドから使えるかどうかは、使うときに確かめる。

モジュール名を `pc`（予測符号化）にしたのは、PC-ALM が双対変数のステップサイズ $\alpha = 0$ で通常の予測符号化（PC）に退化し、PC も同じモジュールに収まるからである。

PC-ALM のクラスは `mujou.*` のトップレベルには公開せず、`mujou.pc` からだけ公開する。基盤（`mujou.Node` など）と更新手法の区別を、名前に残すためである。別の更新手法を足すときも、`mujou.pc` と同じように手法ごとのモジュールにする。`mujou.pc` の中のクラス名は、実装するときに決める。

### 検証済みの事項

skill `pc-alm` の 1〜6 節は、記事の定義を勾配まで展開したものである。2026-10-11 に、勾配式が有限差分と一致することを数値で確認した（tanh、4 層、誤差 3e-9）。同時に、不動点で重みの更新が BP の勾配と一致することも確認した。この一致は非線形でも成り立つが、不動点への収束が保証されるのは線形の場合だけである。この確認を再現するテストはリポジトリに無く、結果の記録は `memory/reference_pc_alm.md` にある。

### 記事が触れていない点

記事は、双対変数の初期化・リセット方針、非同期スケジューリング、ペナルティ係数の調整（記事では ½ に固定）には触れていない。

### 連続時間形

mujou のノードは独自の周期で非同期に動くので、記事の離散更新を実行のタイマーの時間（既定はグローバルタイマー）に対する微分方程式として扱い直す。式・時定数・離散化・未解決の問いは [PC-ALM の連続時間系](pc-alm-continuous-time.md) にまとめてある。
